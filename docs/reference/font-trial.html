Font trial: 8 faces on the giant YAHYA

Throwaway reference for the Phase 1 font pick (D-01 to D-08). Measured numbers: docs/reference/font-metrics.md. Faces that max out at 700 stay at 700 and print "max 700".

Pass / fail criteria

  • The Y arms and A apexes hold together at giant size with negative tracking (check the actual word).
  • No slanted style is needed or used anywhere (D-05).
  • Tabular figures available: a tnum feature, or figures tabular by default (D-06).
  • A variable file (or 2 static weights) can be self-hosted under the licence.
  • 16px body reads comfortably on black.
  • Latin-Extended is not a criterion (D-07).
