# Phase 5 — UI Design Contract

## Spacing Scale

Inherited from `tokens.css` (multiples of 4 only):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Snap box inflation around target; tag padding (vertical); hint nudge travel |
| sm | 8px | Tag padding (horizontal); tag viewport clamp inset; focus-tag gap to the letter |
| md | 16px | Hero caption offset below letter; gap between hint and Next link |
| lg | 24px | Grid margin (desktop); phone rail left inset (24px, LTR-06) |
| xl | 32px | unused here |
| 2xl | 48px | unused here |
| 3xl | 64px | unused here |

Exceptions:
- Rail geometry stays on existing tokens: `--rail-size` 30px (22px under 820px), `--rail-col` 56px (36px phone), `--rail-gap` 8px (28px coarse). These are letter sizes, not spacing.
- Touch targets stay at `--hit-min` 44px (coarse pointer) for rail letters, Next, header links. The hint line is not interactive, so no target size applies.
- Cursor idle square is 16px and the dot is 4px (both multiples of 4). Hairlines are 1px (border width, not spacing).
- Tag-to-box gap is 12px (the v7 `tagPos` gap, kept in `placeTag(..., gap = 12)`); this is a placement constant, not a layout spacing token.

## Typography

No new sizes or weights. Everything in this phase reuses the existing contract: 4 sizes (12 label, 16 body, 24 heading, display clamp) and 2 weights (400, 700).

| Role | Size | Weight | Line Height | Used for in this phase |
|------|------|--------|-------------|------------------------|
| Body | 16px | 400 | 1.5 | not used by new pieces |
| Label | 12px, uppercase (`.t-label`) | 400 | existing `.t-label` ratio (1.4) | First-visit hint line; cursor/focus Label tag; hero captions (existing) |
| Heading | 24px | 700 | 1.2 | not used by new pieces |
| Display | hero `min((100vw - 2*margin)/2.188, (100svh - 320px)/0.76)`; rail 30px / 22px phone | 700, `font-stretch` 75%, line-height 0.76 | 0.76 | The five letters, in flight and at rest |

Rules:
- Moving letters keep `--yahya-fit` 2.188, `--yahya-track`, and the hero-only Y-A kern (`margin-right: var(--yahya-kern)` on Y). Never re-measure with 2.155.
- Letters always fly laid out at hero `font-size` with scale at most 1 (research Pattern 1); the rest state is real `font-size`. Never animate `font-size`.
- The hint and tag use `.t-label` exactly (no new class, no new size).

## Color

Inherited from `tokens.css`. No new colour values.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--color-ground` #0b0b0b | Page ground; the opening's "black ground" (nothing else is painted) |
| Secondary (30%) | `--color-ink` #f0f0f0 / `--color-hair` #2e2e2e | Letters at rest, cursor square and dot (before blending), tag fill; hairlines |
| Accent (10%) | `--color-accent` #5fae84 | see reserved list |
| Muted text | `--color-dim` #8e8e8e (about 6:1 on ground, passes AA) | First-visit hint text |
| Destructive | none | no destructive actions in this phase |

Accent reserved for (unchanged from DSGN-01; this phase adds no accent use):
1. The current section's rail letter, derived from the page only (`aria-current="page"`), never from hover, focus or the cursor.
2. Hero caption numbers on hover/focus/active (existing `.num` rule).
3. Existing accent uses from Phases 3-4 (unchanged).

Phase 5 accent timing (decision, resolves research Open Question 3): the current letter turns accent at slide start. The accent rule is scoped to `data-mode="rail"` OR `data-flight="out"`, so the letter is green while it travels, not 820ms later at settle. On return to the hero (`data-flight="in"`) no letter is accent (hero letters are ink; only caption numbers react to hover).

Cursor colour rules (D-19):
- Square hairlines, dot: `--color-ink` with `mix-blend-mode: difference` set on the fixed root element itself (a direct child of `<body>`, own stacking context). Plain ink is the fallback where blending is unsupported.
- Tag: separate fixed root, no blend. Fill `--color-ink`, text `--color-ground` (inverse, about 17:1), no border. Same visual style is shared with the keyboard focus tag via one CSS rule.
- The cursor never uses accent.

Opening: the black ground is `--color-ground`; no cover element, no gradient, no colour flash.

## Layout and Visual Contract

### 1. Letter glide (LTR-03, DSGN-04, D-11..D-15)

| Property | Contract |
|----------|----------|
| Trigger | `onSlideStart({from, to})`. `dest = to === 0 ? hero : rail`. No-op if `dest` equals the mode the letters are at or heading to (rail-to-rail paging 01..05 never moves the rail, D-13) |
| Total | X lands at 600ms (`--dur-letters`); last letter (index 4) finishes at 4x30 + 100 + 600 = 820ms. Track lands at 600ms; the cursor resnap waits for both |
| Stagger | 30ms per letter, reading order Y A H Y A (index 0..4), both directions (D-12) |
| X axis | CSS individual `translate: dx 0`, 600ms, `--ease-page` (`cubic-bezier(0.77,0,0.18,1)`); `--ease-retarget` when `retarget` is true. `fill: both` |
| Y and scale | `transform: translateY(dy) scale(s)`, `transform-origin: 0 0`, 600ms, delay = stagger + 100ms, easing NEW `--ease-settle: cubic-bezier(0.5, 0, 0.2, 1)`, `fill: both`. Never ahead of X (verified numerically in research) |
| Geometry | Fly in hero geometry, scale <= 1. To rail: stay `data-mode="hero"` with `data-flight="out"`, animate toward measured rail rects, then on settle write `data-mode="rail"`, remove `data-flight`, cancel animations in the same frame. To hero: write `data-mode="hero"` + `data-flight="in"` at start, animate from rendered rail rects to identity |
| Origin of "from" | Rendered `getBoundingClientRect()` read before `cancel()` (retarget-safe); "to" measured from resting layout, never from the in-flight track (D-15) |
| Ownership | `data-mode` is written by the glide runner only after hydration; React renders it from the server prop once |
| Properties | `translate`, `transform`, `opacity` only |
| Bounds | No easing control point y outside [0,1]; no overshoot; no bounce |
| Resize mid-flight | Cancel letter animations, write destination `data-mode`, clear `data-flight`. Letters never stranded. At rest no JS runs on resize |
| Phone (<= 820px) | Same glide; rail rests 24px from left (`left: var(--space-lg)`), 22px letters, 36px rail column. Hero captions do not exist on phone (visually hidden names), so the caption fade is skipped there. Test at 390x844 including a scrolled Index (pass held `scrollY` offset in `SlideStartEvent`) |
| Current marker | Rail letter with `aria-current` is accent plus the existing `.now` vertical numbered name (non-colour cue). `.now` renders whenever target != 0 and is hidden in hero mode by CSS |
| Hit areas | Each letter's own box via `::before` (existing). Letters are never `inert`; focus on a clicked letter must survive the glide |
| Stand-in removed | `lettersMode`, `railEnter`, `lettersInert`, animator `letters` target, `rail-in` keyframe are deleted |

Captions (D-14):
- Hero captions ("01 Achievements" ...) fade out over `--dur-ui` (150ms, `--ease-ui`) at slide start when leaving the hero. During flight: `opacity: 0`, `pointer-events: none`.
- Returning: during `data-flight="in"` captions sit at `opacity: 0; transition: none` (no flash), and fade up over `--dur-ui` only after the letters settle.
- Role line and Index grid lines belong to page 00 and ride with the track (no special handling).

### 2. Opening (EXP-01, D-01..D-06)

| Property | Contract |
|----------|----------|
| When | Index only (D-02). Fresh load of `/` with flag unset, or first arrival at the Index by paging/navigating (D-03). Never on deep links; a deep link does not consume it |
| Look | The five letters slide in horizontally and land in their hero rest positions. Nothing else is added: no curtain, no grid-line draw, no counter, no logo, no fade-in of the ground |
| Direction (decision, resolves Open Question 1) | Fresh load: letters enter from the right (travel left to rest), matching the site's forward direction. Paged arrival (D-03 path): letters enter from the left, matching the track bringing page 00 in from the left. Start offset = viewport width + 24px so each letter starts fully offscreen |
| Motion | `translate` X, 600ms, `--ease-page`, 30ms stagger Y A H Y A, `fill: both` |
| Chrome | Header, footer, hero captions, role line, Index grid lines are `opacity: 0` until the letters land, then fade to 1 over `--dur-ui` (150ms) together (decision, resolves assumption A3: "black ground" means chrome is also hidden) |
| Duration | 4x30 + 600 + 150 = 870ms (< 1s). Real page DOM is already rendered underneath |
| Pre-paint | Inline script sets `html[data-opening="pending"]` only when path is `/`, motion is not reduced, storage is readable and flag unset. Failsafe: removes it after 3000ms if the bundle never claims it. JS off or storage throws: nothing hidden |
| Skip (D-06) | pointerdown or keydown (not Tab, Shift+Tab, bare modifiers, or Ctrl/Meta/Alt chords) jumps to the end state instantly via `finish()`; the skipping input is consumed (keydown `preventDefault` + `stopPropagation` in capture; the following click suppressed once). Wheel and swipe do not skip, but a page change cancels the opening and runs the normal glide |
| Flag | Written when the opening starts or is skipped, forever, try/catch |
| Reduced motion | Script never hides anything; final state is shown at once; flag still written |
| a11y | Pure decoration; content already in DOM; nothing announced; no focus trap |

### 3. First-visit hint (NAV-06, D-07..D-10)

| Property | Contract |
|----------|----------|
| Element | A plain text `<span>` in the footer, `.t-label`, `--color-dim`, not interactive, not announced (no `aria-live`, no `role`). Empty on the server; text chosen after mount |
| Placement desktop | Footer grid columns 6-9, right-aligned so it ends 16px (`--space-md`) before the Next link in columns 10-12; baseline aligned with counter and Next |
| Placement phone (<= 820px) | Between counter and Next in the same footer row, `min-width: 0`, single line, `white-space: nowrap`, right-aligned and 16px from Next; never wraps, never overlaps the progress bar (bar stays at the footer bottom edge), never covers page content. If it cannot fit at 360px width, it is hidden for that visit (never truncated with an ellipsis) |
| Copy | See Copywriting Contract |
| Timing | Shows 1000ms after the opening ends or is skipped; 1500ms after load when no opening runs. Ends on the first page change or 8000ms after showing, whichever first. Fade in and out over `--dur-ui` (opacity only) |
| Nudge | Once, when the hint appears: Next link `translate` 0 -> 4px (`--space-xs`) -> 0 on X only, 300ms total, `--ease-ui`, no overshoot past the start. Skipped under reduced motion |
| Memory | Own `localStorage` key, separate from the opening's, written when the hint appears; never returns. All access in try/catch |
| Routes | Every route |

### 4. Rail labels and focus tag (LTR-04, D-17, D-18)

| Property | Contract |
|----------|----------|
| Focus (keyboard) | `.nav[data-mode="rail"] .letter:focus-visible` shows the section name tag to the right of the letter: left edge = rail column edge + 8px (`--space-sm`), vertically centred on the letter box, fade over `--dur-ui`. Text is the existing visually-hidden caption, un-clipped (real text, readable by screen readers, no JS needed) |
| Hover | Cursor tag when the custom cursor runs. Fallback `html:not([data-cursor]) .nav[data-mode="rail"] .letter:hover` shows the same CSS tag (touch hybrids, forced colours, no-cursor mice) |
| Tag text | Number plus name, e.g. "01 Achievements" (from `content/`, as `data-cursor-tag`) |
| Tag style | `.t-label`, ink fill, ground text, padding 4px 8px (`--space-xs` `--space-sm`), no radius, no border, no shadow. One shared CSS rule serves focus and cursor tags |
| Accent | Focus/hover never colour a rail letter; the focus outline stays `--color-ink` (existing) |

### 5. Custom cursor (EXP-03, D-16..D-19)

| Property | Contract |
|----------|----------|
| Form | Variant (a): a hard-edged ink square (1px hairlines, no fill, no radius) plus a 4px solid dot at the exact pointer position |
| Tracking | Dot and idle square written as `translate3d(x,y,0)` directly in `pointermove`. 1:1, no rAF, no lerp, no spring, no transition while following |
| Idle | 16px square centred on the pointer, dot 4px |
| Snap | Over a snap target the square becomes the target rect inflated by 4px (`--space-xs`) on every side, built from four transform-only hairlines (translate + scaleX/scaleY). Transition `--dur-ui` `--ease-ui` runs only on snap/unsnap (attribute set then cleared after `--dur-ui`), never while following. Shape changes only; the dot keeps tracking the pointer |
| Snap targets (D-16) | `el.closest("a, button, [data-cursor-snap]")`: hero and rail letters, header and footer links, Next, Resume, content links/buttons. `data-cursor-snap` is the opt-in for Phase 6 non-link targets |
| Tag (D-17) | Shown only for letters (section name) and external links / Resume (destination or action) via `data-cursor-tag`. Internal chrome links (Next, Say hi, header) snap the square with no tag. Placement order right -> above -> below -> left, then clamped 8px (`--space-sm`) inside all four viewport edges. `textContent` only |
| Blend (D-19) | `mix-blend-mode: difference` on the fixed square/dot root. Tag is a separate root without blend |
| Visibility | Nothing rendered before the first real `pointermove` (`opacity: 0`; pointer position is `null`, never (0,0), WR-05). Hidden when the pointer leaves the window |
| Native cursor (WR-07) | `cursor: none` only via `html[data-cursor]`, set by script on the first real mouse/pen move, and only inside `@media (hover: hover) and (pointer: fine) and (forced-colors: none)`. Never from first paint. Removed on unmount, on a touch pointerdown and when the media stops matching |
| Keeps native | Touch (`hover: none` / `pointer: coarse`), forced-colours, JS off, cursor chunk failed |
| Paging | `onSlideStart` releases the snap immediately (kept only when moving rail letter to rail letter with from, to both != 0). After both `onLanded` and glide-settled, re-snap with `document.elementFromPoint` |
| Layers | `aria-hidden="true"`, `pointer-events: none`, `z-index` above header/footer (30+, skip link stays reachable). Loaded lazily (`import()`) so it stays out of the 150 kB gzip gate |

### 6. Motion rule and reduced motion (DSGN-04, A11Y-04)

Single rule: movement is horizontal, fast, decisive; the only vertical travel is the letters settling into or out of the rail column and it always finishes after X. No bounce, no overshoot, no bezier y outside [0,1].

Tokens (all in `tokens.css`; NEW marked):

| Token | Value |
|-------|-------|
| `--dur-page` / `--dur-letters` | 600ms |
| `--dur-ui` | 150ms |
| `--stagger` | 30ms |
| `--ease-page` | cubic-bezier(0.77, 0, 0.18, 1) |
| `--ease-retarget` | cubic-bezier(0.3, 0.6, 0.18, 1) |
| `--ease-ui` | cubic-bezier(0.16, 1, 0.3, 1) |
| `--ease-settle` NEW | cubic-bezier(0.5, 0, 0.2, 1) |
| `--glide-y-lag` NEW | 100ms (also read by JS) |
| `--open-offset` NEW | not a token; computed in JS as viewport width + 24px |

Reduced motion (live, via `matchMedia` change listener; WAAPI callers check it themselves because `--dur-*` only governs CSS):

| Motion | Reduced behaviour |
|--------|-------------------|
| Letter glide | Write destination `data-mode` at slide start; no animations |
| Caption fade, hint fade, cursor snap, hover/focus colour | `--dur-*` is 0ms: instant |
| Opening | Final state at once, flag written, script never hides |
| Hint nudge | Skipped |
| Cursor | Still 1:1; shape changes instant |

## Copywriting Contract

All strings live in `content/site.ts` (no literals in components).

| Element | Copy |
|---------|------|
| Primary CTA | None new. Existing: "Next, {Section}" (`footer.nextPrefix`), "Back to the start" on the last page |
| Hint, fine pointer (`site.hint.fine`) | "Scroll or use the arrow keys" (rendered uppercase by `.t-label`) |
| Hint, touch (`site.hint.coarse`) | "Swipe sideways" |
| Rail letter tag | "{number} {name}" from `sections`, e.g. "01 Achievements" (existing content, no new strings) |
| External link / Resume tag | Names the action or destination in `content/`, e.g. Resume uses "Resume (PDF)" (existing `site.resume.label`); other external tags are Phase 6 content |
| Empty state heading/body | Not applicable: no data-driven views in this phase |
| Error state | Not applicable for UI. Storage failure is silent by design: the opening plays at most once per page load and the hint is simply not remembered. No user-facing message |
| Destructive confirmation | Not applicable: no destructive actions in this phase |

Screen reader: opening and hint are not announced; the cursor is `aria-hidden`; focus tag is real text; the existing live region keeps announcing page changes.
