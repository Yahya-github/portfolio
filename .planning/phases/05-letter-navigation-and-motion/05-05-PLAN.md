  <behavior>
    - constants: HINT_DELAY_AFTER_OPENING_MS 1000, HINT_DELAY_NO_OPENING_MS 1500, HINT_VISIBLE_MS 8000
    - initialHint() -> { phase: "idle", showAt: null, hideAt: null }
    - load at 0 without opening -> phase "waiting", showAt 1500; with openingPending true -> phase "waiting", showAt null
    - opening-done at 900 while waiting with showAt null -> showAt 1900; opening-done when showAt is already set or phase is not waiting -> same object returned (unchanged)
    - tick at 1499 -> unchanged object; tick at 1500 -> phase "shown", hideAt 9500 (showAt + 8000)
    - tick at 9500 while shown -> phase "done"
    - page-change while waiting or shown -> phase "done" (D-09/D-10 first page change ends it); any event after done -> same object
    - nextWakeAt: waiting with showAt -> showAt; waiting without showAt -> null; shown -> hideAt; idle/done -> null
    - every transition returns a new object; inputs are never mutated (freeze inputs in tests with Object.freeze)
  </behavior>
