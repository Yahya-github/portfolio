# Phase 1 — UI Design Contract

> Visual and interaction contract for the dark Swiss horizontal portfolio. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> Phase 1 writes no product code. This contract is what the rewritten design doc (`docs/superpowers/specs/2026-11-03-portfolio-design.md`, revision 5), the font trial page and the throwaway v7 sketch must express. Phases 3 to 6 implement it as `styles/tokens.css` plus CSS Modules. Where a value says "trial", the Phase 1 font trial fixes it and the design doc records the final number.

**Sources:** CONTEXT.md D-01 to D-29 (locked), `docs/reference/swiss-horizontal-v6.html` (locked visual reference), REQUIREMENTS.md, ROADMAP.md, PROJECT.md Key Decisions, research SUMMARY/PITFALLS/ARCHITECTURE, ./CLAUDE.md stack, skills `portfolio-design`, `portfolio-voice-and-facts` and `anti-vibe-design`. If any of these conflict, the newer CONTEXT.md decision wins. The light-design "no lines, no small labels" rule was retired on 2026-11-05 (PROJECT.md Out of Scope), so the v6 hairlines and labels are allowed, under the limits below.

## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| `--space-xs` | 4px | Caption number to name gap, inline nudges |
| `--space-sm` | 8px | Rail letter gap, label line gaps, list row inner gap |
| `--space-md` | 16px | List row vertical padding, phone grid gutter and margin, paragraph spacing |
| `--space-lg` | 24px | Desktop grid gutter (`--grid-gutter`) and outer margin (`--grid-margin`), gap between a heading and its content |
| `--space-xl` | 32px | Gap between groups inside a page (title to list) |
| `--space-2xl` | 48px | Gap between major blocks on a page |
| `--space-3xl` | 64px | Page-level breathing room above poster type |
| `--space-4xl` | 96px | Distance from the hero word's bottom edge to the footer (v6 used 92, rounded to the scale) |

Rhythm rule: more space between groups than within (Swiss principle). Within a list row use `sm`/`md`; between a title and its list use `xl`; between blocks use `2xl` or more. Never the same padding on every element.

Exceptions:
- Frame offsets: header height 72px (`--frame-top`), footer height 56px (`--frame-bottom`). Pages pad by these so content never sits under the fixed frame. Both are multiples of 4.
- Rail column: non-hero pages pad left by `--grid-margin + 56px` desktop (rail width 32px plus 24px gap) and `16px + 36px` on phones, so content never sits under the rail.
- Phone rail inset: rail letters sit 24px from the left screen edge (research Decision 3, LTR-06). Swipe starts within 20px of the left edge are ignored for paging.
- Touch targets: every link, rail letter and control is at least 44x44px hit area on touch devices (padding may extend past the glyph).
- Hairline thickness 1px and progress bar 2px are line weights, not spacing.

### Grid

| Token | Desktop (>= 1024px) | Tablet (821-1023px) | Phone (<= 820px) |
|-------|---------------------|---------------------|------------------|
| Columns | 12, `repeat(12, minmax(0, 1fr))` | 12 | 12 in tokens; most pages collapse to 1 stacked column (Phase 6 designs them) |
| `--grid-gutter` | 24px | 24px | 16px |
| `--grid-margin` | 24px | 24px | 16px |
| Nested blocks | `grid-template-columns: subgrid` so every block lands on master columns | same | same |

- Every page is `100svh` tall (never `dvh` for fit maths) and designed to fit 1366x768 and 1440x900 without scroll (NAV-07). Overflow at zoom or on short screens scrolls vertically inside the page.
- Every element starts and ends on a column line. Text is flush left, ragged right. No centred text anywhere.

## Typography

One family (D-06). Two weights. Four set sizes, plus one fitted Poster role that is not a free size: it is computed from the grid width and one per-font constant.

| Role | Size | Weight | Line Height | Tracking | Used for |
|------|------|--------|-------------|----------|----------|
| Label | 12px | 400, uppercase | 1.3 | +0.02em | Header, footer counter and Next, hero letter captions, rail section names, meta lines, project row numbers, dates in the Experience table |
| Body | 16px | 400 | 1.5 | 0 | Paragraphs, list details, project problem/role/result lines |
| Heading | 24px | 700 | 1.2 | -0.015em | List item names (results, roles, compact project names), rank ("1st"), About lead paragraph (weight 400, line height 1.35) |
| Display | `clamp(64px, 9vw, 168px)` | 700 | 0.88 | -0.05em, margin-left -0.03em to optically align flush left | Exactly one Display group per page (see Compositions) |
| Poster (hero YAHYA only) | `calc(var(--grid-width) / var(--yahya-fit))`, capped by `min()` against `100svh` so it fits short screens | display weight (700 default; the trial may set one value in 700-800, which then replaces 700 site-wide) | 0.76 | -0.04em (trial sets the final value) | The giant YAHYA. Rail letters are the same glyphs scaled down by transform, resting rail size 30px desktop, 22px phone |

Rules:
- Exactly 2 weights ship: 400 and the display weight. No 200 light (the v6 75/75 at 200 is retired), no 500, no 800 second heavy.
- No italics anywhere (D-05). Emphasis is weight, size or the accent.
- Counters and `75/75` use `font-variant-numeric: tabular-nums` (D-06).
- Never animate `font-size`. Size changes are transforms only (PITFALLS 5 and 10).
- The hero word is hidden until the font is ready (`document.fonts.load()` with a 300ms timeout) so the fitted word never reflows. `--yahya-fit` lives in `tokens.css` next to the font choice.
- Body paragraphs max 60ch.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--color-ground: #0b0b0b` | The single flat ground: pages, header, footer. No second surface colour exists; there are no cards |
| Secondary (30%) | `--color-ink: #f0f0f0` (17.27:1 on ground) | All type, the progress bar, YAHYA at rest. Off-white, not #fff, to avoid halation |
| Secondary support | `--color-dim: #8e8e8e` (6.01:1) | Label-role metadata only: caption numbers, dates, the second line of a list item, the Projects intro line. Never for a fact that only exists in grey |
| Structure | `--color-hair: #2e2e2e` (1.45:1, non-text) | 1px hairlines only where real structure exists: header bottom rule, results list, compact project rows, Experience table, the seam between pages. Not under titles, not as decoration |
| Accent (10%) | `--color-accent: #5fae84` (7.38:1 on ground) | See reserved list |
| Destructive | none | The site has no destructive actions, so there is no destructive token |

Accent reserved for exactly these:
1. The current section's rail letter (LTR-05), always paired with a non-colour cue: its numbered section name stays visible beside it (other letters show their name only on hover/focus) and `aria-current="page"`.
2. Hover and focus colour of the YAHYA letters, their captions, the Say hi lines and inline text links.
3. The focus ring: `outline: 2px solid var(--color-accent); outline-offset: 4px` on every focusable element.
4. The `75/75` numeral on Achievements, the single emphasis figure of the site.
5. Cursor variant (b) stroke, if that variant wins.

Never accent: body text, backgrounds, fills, hairlines, the progress bar, photos, the footer counter, any second numeral. Photos are greyscale so nothing else competes with the green (D-22). Green carries no visible "nature" theme (D-27).

Contrast rule: every text token is at least 4.5:1 on `#0b0b0b`; no grey text darker than `#8a8a8a` (5.7:1). If the ground hex changes, recompute and record ratios in the doc.

## Motion Contract

One rule (DSGN-04): movement on the horizontal axis, fast and decisive, no bounce, no overshoot. Only `transform` and `opacity` animate.

| Token | Value | Used for |
|-------|-------|----------|
| `--dur-page` | 600ms | Track slide (`translate3d(calc(var(--page) * -100vw), 0, 0)`) and progress bar |
| `--dur-letters` | 600ms, stagger 30ms per letter | Hero to rail FLIP (WAAPI, transform translate + scale only, letters laid out large and scaled down) |
| `--dur-ui` | 150ms | Colour change on hover/focus, caption fade, cursor shape change |
| `--dur-open` | under 1000ms total | First-visit opening (EXP-01), skippable by any click or key, never repeats |
| `--ease-page` | `cubic-bezier(0.77, 0, 0.18, 1)` | Track, progress bar, letters (from v6) |
| `--ease-ui` | `cubic-bezier(0.16, 1, 0.3, 1)` | Colour and opacity changes |

- Banned: any curve with a control point above 1 (the v6 `.big` overshoot `cubic-bezier(.34,1.56,.64,1)` is retired), springs, parallax, vertical slide-ins (the v6 `translateY(16px)` reveal is retired).
- Every animation is interruptible: new input retargets, it never queues.
- Reduced motion (A11Y-04): every `--dur-*` becomes `0ms`. Page change, letter move, opening, hint and cursor shape change are instant. Paging still works.
- `will-change` only during a transition.

### Cursor (D-18, D-19)

- Tracks the pointer 1:1: position is written every `pointermove`, no lerp, spring or lag. Only shape changes animate (`--dur-ui`).
- Hidden on `(hover: none)` or `(pointer: coarse)`; native cursor returns there and in forced-colours mode.
- v7 offers 3 toggleable variants (toggle key `C`, plus a small toggle row in the v7 sketch header only): (a) a hard-edged square outline in ink that snaps around the hovered letter or link and shows the section name as a Label; (b) a fine 1px crosshair or registration mark in the accent; (c) the native cursor plus a Label context tag next to it over the YAHYA letters. Yahya picks one; the doc records it and the requirement replaces the "custom cursor" out-of-scope line.

## Copywriting Contract

Voice: first person, plain, specific, no em dashes, no "it's not X, it's Y", no sales words (`portfolio-voice-and-facts`). Interface microcopy below is locked; content copy comes only from verified facts.

| Element | Copy |
|---------|------|
| Primary CTA | Footer Next control: "Next, {Section name}" (e.g. "Next, Achievements"); on the last page "Back to the start" |
| Secondary CTA (Projects) | "Read the deep dive" (Facturo to `/projects/facturo/`) |
| Header links | "Resume (PDF)" and "Say hi" |
| Say hi lines | "Email", "LinkedIn", "GitHub", "Resume (PDF)" |
| Email copy success | "Copied {address}" in the status line, replaced after 4 s by the plain address |
| Email copy error | "Copy didn't work. The address is {address}, select it to copy." The `mailto:` href stays on the line, so no-JS visitors can still email |
| Empty state heading | Not applicable as a screen: all content is static and server-rendered. The one honest "empty" item is Showdown AI |
| Empty state body | Showdown AI result line: "In progress, nothing built yet" (never shown as finished work) |
| Image fallback | Portrait alt: "Yahya Hallani at DevFest Montreal 2026" (event name from the source file; confirm wording with Yahya). Screenshot alts describe what the screen shows |
| Error state (missing route) | 404 copy is Phase 7 (SEO-02); it must lead back with "Back to the start" |
| Captions | "01 Achievements", "02 Projects", "03 Experience", "04 About", "05 Say hi" |
| Counter | "00 / 05" format, two digits, tabular |
| Skip link | "Skip to content" |
| Live region on page change | "{Section name}, page {n} of 6" |
| Destructive confirmation | none: the site has no destructive actions |

Fact guards for every phase: CCC is shown only as "perfect score, 75/75" (the "top 1" scope is unconfirmed). Freelance reads "2025" onward. No phone number. No CRC contest platform. Atlantis line counts are confirmed with Yahya before use.
