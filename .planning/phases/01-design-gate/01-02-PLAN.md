Layout formulas (from UI-SPEC grid; use them in both the metrics script and the page):
- Hero grid width (no rail): `Gh = W - 2*24` desktop; phone 390 -> `390 - 2*16 = 358`.
- Content grid for pages 01-05 (rail padding): desktop `G = W - 24 - (24 + 56) = W - 104`; phone `G = 390 - (16 + 36) - 16 = 322`.
- Column width `c = (G - 11*g)/12`, g = 24 desktop, 16 phone; span of n columns = `n*c + (n-1)*g`.

- Poster YAHYA size = `min(Gh / fit, Hb / 0.76)` with `Hb = H - 72 - 56 - 96 - 96` (frame top, frame bottom, hero bottom gap, role/proof block). Report which bound won.
