## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-08 | Tampering (script injection) | vercel.json CSP | mitigate | `default-src 'self'`, `object-src 'none'`, `base-uri 'self'` and `form-action 'self'`. `script-src 'unsafe-inline'` is accepted only because the export inlines RSC payload scripts (there is no server for nonces) and the page takes no user input. |
| T-02-09 | Tampering (clickjacking) | vercel.json | mitigate | `frame-ancestors 'none'` + `X-Frame-Options: DENY` |
| T-02-10 | Information disclosure (indexing previews) | vercel.json + layout metadata | mitigate | `X-Robots-Tag: noindex, nofollow` on every path (this covers the PDF and the previews) plus the meta robots tag. No robots.txt Disallow. |
| T-02-11 | Elevation of privilege | .github/workflows/ci.yml | mitigate | `pull_request` (not `pull_request_target`), `permissions: contents: read`, no secrets, `--frozen-lockfile` |
| T-02-12 | Tampering (silent CSP regression) | csp.spec.ts | mitigate | The real vercel.json CSP is injected into the local run with an assertion of zero violations; the negative control proves detection works |
| T-02-13 | Tampering (action supply chain) | ci.yml action tags | accept | Official actions on major tags. SHA pinning is optional for a read-only workflow with no secrets. |
