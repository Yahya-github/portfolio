    orbit.ts (UI-SPEC Robot stage; RESEARCH "Orbit maths"):
    - `Pose = Readonly<{ yaw: number; pitch: number }>`; `PITCH_LIMIT = Math.PI / 6`; `START_POSE = { yaw: -Math.PI / 5, pitch: Math.PI / 12 }`
    - dragTo(p, dx, dy, stageW, allowPitch): dx = stageW gives +2π yaw; pitch += dy/stageW*2π clamped to ±PITCH_LIMIT; allowPitch false keeps pitch
    - keyStep: ArrowLeft -π/12 yaw, ArrowRight +π/12, ArrowUp +π/18 pitch (clamped), ArrowDown -π/18, Home -> START_POSE, any other key -> null
    - touchIntent(dx, dy, threshold = 8): null while hypot < threshold; "orbit" when |dx| > |dy|; else "scroll"
    - autoRotateYaw(p, dtMs, turnMs): yaw + dtMs/turnMs*2π; turnMs <= 0 returns p unchanged
    - `interface AutoRotateInputs { readonly reducedMotion; motionOn; inView; visible; touched: boolean }`; shouldAutoRotate true only for reducedMotion=false, motionOn, inView, visible, touched=false (all 32 combinations tested)
    ease.ts:
    - cubicBezier(x1,y1,x2,y2) returns (t) => y with t clamped 0..1, f(0)=0, f(1)=1, monotone for the two site curves, within 1e-3 of reference values at t=0.5 (ease-page ≈ 0.5 by symmetry, verify) ; parseCubicBezier("cubic-bezier(0.77, 0, 0.18, 1)") -> [0.77,0,0.18,1], invalid string -> null
    mesh-format.ts, layout little-endian, HEADER_BYTES = 40:
    - offset 0 magic "RBT1" (4 ASCII bytes); 4 vertexCount u32; 8 indexCount u32; 12 indexType u8 (2 or 4); 13-15 zero padding; 16-39 bboxMin xyz then bboxMax xyz as f32
    - then positions Int16 x4 (normalized, w = 0) = 8 bytes per vertex; normals Int8 x4 = 4 bytes per vertex; indices indexType bytes each
    - parseMesh(buf) returns { vertexCount, indexCount, indexType, bboxMin, bboxMax, positions: Int16Array, normals: Int8Array, indices: Uint16Array | Uint32Array } or null when: byteLength < 40, wrong magic, indexType not 2/4, vertexCount 0, indexCount 0 or not a multiple of 3, indexType 2 with vertexCount > 65536, byteLength !== 40 + 12*vertexCount + indexType*indexCount, any bbox value non-finite or min > max, any index >= vertexCount
    robot-mesh.mjs:
    - encodeMesh({ positions: Float32Array (xyz), normals: Float32Array (xyz), indices: Uint32Array }) -> Uint8Array in RBT1 layout; picks indexType 2 when vertexCount <= 65536; quantizes q = round(((p - min) / (max - min || 1)) * 2 - 1) * 32767 per axis; normals round(n * 127)
    - placeholderMesh() -> a box body plus four cylinder wheels (16 segments) as {positions, normals, indices}, deterministic
    - Round trip: parseMesh(encodeMesh(m).buffer) is non-null; de-quantized positions are within (max-min)/32767 of the input on every axis
  </behavior>
