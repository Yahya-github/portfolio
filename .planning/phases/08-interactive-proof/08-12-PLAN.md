    2. GL: one VAO; position attribute `vertexAttribPointer(0, 4, gl.SHORT, true, 8, 0)`, normal `(1, 4, gl.BYTE, true, 4, 0)`; element buffer UNSIGNED_SHORT or UNSIGNED_INT per indexType; `gl.disable(gl.CULL_FACE)`; depth test on. Vertex shader de-quantizes `pos = uMin + (aPos.xyz + 1.0) * 0.5 * (uMax - uMin)`, centres on the bbox centre, applies yaw then pitch rotation and a perspective camera (fov 30 degrees, distance fitting the bbox radius). Fragment shader Lambert: key light from upper left (about 45 degrees left of camera, 35 degrees up), `c = mix(0.290, 0.878, max(dot(normalize(vN), uLight), 0.0))` (#4a4a4a to #e0e0e0), no specular, no tint. Clear colour parsed from `--color-ground`.
    3. Live: insert the canvas into `[data-model-slot]` at opacity 0, draw START_POSE, then set `figure.dataset.modelState = "live"`, add `role="group"`, `aria-roledescription`, `aria-label` (viewer copy from content/robot.ts), `aria-describedby="robot-viewer-desc"`, `tabindex="0"`; canvas opacity 1 (CSS transition --dur-fade); after the transition (or immediately under reduced motion) set the still `visibility: hidden` (kept in DOM).
    4. Input: pointerdown/move/up with setPointerCapture; mouse/pen -> dragTo(..., allowPitch true); touch -> touchIntent decides on the first 8 px: "orbit" -> yaw only, "scroll" -> release and let the page scroll (never preventDefault on vertical intent; canvas has touch-action pan-y pinch-zoom). keydown on the figure: keyStep; animate to the target over --dur-ui with --ease-ui (instant under reduced motion); Arrow keys call preventDefault only when handled; Tab untouched. Reset button and Home: animate to START_POSE over --dur-page with --ease-page. No wheel handler. focus/blur on the figure swaps the hint text between hintDrag and hintKeys.
    5. Auto-rotate: inputs reducedMotion (matchMedia with change listener), motionOn (`html.dataset.motion !== "off"`, observed with a MutationObserver on html attributes), inView (IntersectionObserver), visible (`!document.hidden`), touched (set on first pointerdown, handled key, or Reset; also sets `html.dataset.modelTouched = ""`). RAF runs only while shouldAutoRotate(...) or a step animation is active; yaw advances by autoRotateYaw with turnMs = --model-turn token or 24000.
    6. webglcontextlost: preventDefault, remove the canvas, restore the still visibility, clear modelState and the group attributes. Cleanup cancels RAF, disconnects observers, deletes GL objects, removes listeners and the canvas, restores the still.
    Keep functions under 50 lines (split into setupGl, draw, input, autoRotate helpers in the same file); file under 400 lines.
