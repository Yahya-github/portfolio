Contract:
```ts
export interface WheelSample { readonly dx: number; readonly dy: number; readonly mode: 0 | 1 | 2; readonly t: number; readonly ctrl: boolean; readonly vh: number; readonly legacy?: number }
export type WheelPhase = "idle" | "accumulating" | "scrolling" | "spent";
export interface WheelState { readonly phase: WheelPhase; readonly sumX: number; readonly sumY: number; readonly lastT: number; readonly recent: readonly number[]; readonly peak: number; readonly decayed: boolean; readonly gestureId: number }
export const INITIAL_WHEEL: WheelState; // phase "idle", sums 0, lastT -Infinity, recent [], peak 0, decayed false, gestureId 0
export interface WheelStep { readonly state: WheelState; readonly intent: Direction | null; readonly preventDefault: boolean }
export function stepWheel(state: WheelState, sample: WheelSample, edge: EdgeInfo): WheelStep;
```

  <implementation>
Algorithm for `stepWheel` (keep each helper under 50 lines; never mutate the incoming state):
1. If `sample.ctrl`: return `{ state, intent: null, preventDefault: false }`.
2. `{ x, y } = normalizeDelta(...)`; `mag = Math.max(Math.abs(x), Math.abs(y))`. If `mag === 0` return `{ state: { ...state, lastT: sample.t }, intent: null, preventDefault: state.phase === "accumulating" || state.phase === "spent" }`.
3. `fresh = (state.phase === "spent" || state.phase === "scrolling") && state.decayed && state.recent.length > 0 && mag > FRESH_FLICK_MIN_PX && mag >= FRESH_FLICK_RATIO * Math.min(...state.recent)`. `isNew = state.phase === "idle" || sample.t - state.lastT > GESTURE_GAP_MS || fresh`.
4. New gesture: axis = `Math.abs(x) > Math.abs(y) ? "x" : "y"`; `value = axis === "x" ? x : y`; `dir = value > 0 ? "next" : "prev"`. If `axis === "y" && edge.overflowing && !(dir === "next" ? edge.atEnd : edge.atStart)` -> phase "scrolling", preventDefault false, intent null (D-05: native scroll for the whole gesture). Otherwise phase "accumulating" with sums `(x, y)`, then: `discrete = sample.mode === 1 || (sample.legacy !== undefined && sample.legacy !== 0 && sample.legacy % DISCRETE_NOTCH === 0)`; if `discrete || Math.abs(value) >= WHEEL_THRESHOLD_PX` -> phase "spent", intent dir. preventDefault true. New gestures reset `recent = [mag]`, `peak = mag`, `decayed = false`, `gestureId + 1`.
5. Continuing gesture: `recent = [...state.recent, mag].slice(-3)`, `peak = Math.max(state.peak, mag)`, `decayed = state.decayed || mag <= peak * DECAY_RATIO`, `lastT = sample.t`. Phase "scrolling" -> preventDefault false, intent null. Phase "spent" -> preventDefault true, intent null (the momentum tail is swallowed however long). Phase "accumulating" -> add to sums; dominant = the axis with the larger |sum| (D-04: the gesture's accumulated delta wins); if |dominant sum| >= WHEEL_THRESHOLD_PX -> phase "spent", intent by sign; preventDefault true.
Why `decayed`: a fresh flick only counts after the stream has decayed to half its peak; otherwise the rising edge of the same flick (3, 8, 18, 35, 60) would read as a second flick. Record this in the doc comment as a Claude's-discretion threshold (CONTEXT "Wheel accumulator thresholds") to be tuned in 04-15.
