keys.ts contract:
```ts
export type TargetKind = "control" | "text" | "none";
export interface KeyEventLike { readonly key: string; readonly shiftKey: boolean; readonly altKey: boolean; readonly ctrlKey: boolean; readonly metaKey: boolean; readonly repeat: boolean; readonly defaultPrevented: boolean; readonly targetKind: TargetKind }
export type KeyAction = "next" | "prev" | "first" | "last";
export interface KeyIntent { readonly action: KeyAction; readonly scrollFirst: boolean; readonly scrollBy: "page" | "line" | null; readonly repeat: boolean }
export const KEY_LINE_PX = 40;
export const KEY_PAGE_RATIO = 0.875;
export function keyIntent(e: KeyEventLike): KeyIntent | null;
export function targetKindOf(el: Element | null): TargetKind;
export function resolveScrollKey(intent: KeyIntent, edge: EdgeInfo): "page" | "scroll" | "stop";
```
keyIntent table (UI-SPEC Keyboard):
- "ArrowRight" -> next, scrollFirst false, scrollBy null; "ArrowLeft" -> prev, false, null
- "PageDown" -> next, true, "page"; "PageUp" -> prev, true, "page"
- " " (Space) without shift -> next, true, "page"; " " with shift -> prev, true, "page"
- "ArrowDown" -> next, true, "line"; "ArrowUp" -> prev, true, "line"
- "Home" -> first, false, null; "End" -> last, false, null
- any other key -> null; `repeat` copied from the event
Guards (all -> null): altKey, ctrlKey or metaKey held; defaultPrevented; targetKind "text" (any key); targetKind "control" with key " " (WR-04). Arrow keys and Home/End with targetKind "control" still page.
targetKindOf: null -> "none"; tag A (with href), BUTTON, SUMMARY, or `role` attribute "button" | "link" -> "control"; INPUT, TEXTAREA, SELECT, or `isContentEditable` / `contenteditable="true"` -> "text"; anything else (BODY, H1, MAIN) -> "none".
resolveScrollKey: if `!intent.scrollFirst || !edge.overflowing` -> "page". Direction next: `!edge.atEnd` -> "scroll"; at end: `intent.repeat` -> "stop" else "page". Direction prev mirrors with atStart. first/last -> "page".

swipe.ts contract:
```ts
export interface PointerSample { readonly kind: "down" | "move" | "up" | "cancel"; readonly x: number; readonly y: number; readonly t: number; readonly pointerType: string; readonly id: number; readonly zoomed: boolean }
export type SwipeLock = "none" | "h" | "v";
export interface SwipeState { readonly active: boolean; readonly id: number; readonly x0: number; readonly y0: number; readonly lock: SwipeLock; readonly samples: readonly { readonly x: number; readonly t: number }[] }
export const INITIAL_SWIPE: SwipeState; // active false, id -1, lock "none", samples []
export interface SwipeStep { readonly state: SwipeState; readonly intent: Direction | null }
export function stepSwipe(state: SwipeState, sample: PointerSample): SwipeStep;
export function swipeVelocity(samples: readonly { x: number; t: number }[], now: number): number; // px/ms over the last VELOCITY_WINDOW_MS
```
Constants (UI-SPEC Phone swipe): SWIPE_EDGE_PX 20, AXIS_LOCK_PX 12, AXIS_RATIO 1.5, SWIPE_COMMIT_PX 48, SWIPE_FAST_PX 24, SWIPE_VELOCITY 0.3, VELOCITY_WINDOW_MS 100.
Cases:
- down at x 300 (touch), moves to x 200 over 200ms with dy 5, up -> "next" (finger right-to-left = next)
- down x 100, move to x 200, up -> "prev"
- down at x 10 (< 20) -> never active; any later samples -> null (system back gesture)
- pointerType "mouse" or "pen" -> ignored
- zoomed true on down -> ignored (Pitfall 7: let the browser pan the zoomed view)
- first 12px mostly vertical (dy 20, dx 5) -> lock "v"; later large dx -> still null at up
- lock decision: after |dx| or |dy| reaches 12, lock "h" if |dx| > 1.5 * |dy| else "v"
- 30px horizontal over 50ms (0.6 px/ms) -> "next" (fast short swipe); 30px over 400ms -> null; 47px slow -> null; 48px slow -> "next"
- "cancel" mid-swipe with dx 200 -> null and state reset
- a move/up with a different pointer id than the active one -> ignored
  </behavior>
  <implementation>
Pure modules, no DOM except `targetKindOf`, which only reads `tagName`, `hasAttribute("href")`, `getAttribute("role")`, `getAttribute("contenteditable")` and `isContentEditable` (works in jsdom). Immutable state updates (`samples` kept to entries within the last 100ms plus the latest). Functions under 50 lines. Doc comments cite WR-04, NAV-02, NAV-03, D-08, Decision 3 (20px), Pitfall 7, Pitfall 8. Touch velocity uses `(x_last - x_first_in_window) / (t_last - t_first_in_window)`, absolute value; 0 when fewer than 2 samples or zero elapsed time.
Tests: `tests/pager-keys.test.ts` (`it.each` table for keyIntent, guards, targetKindOf with jsdom-created elements, resolveScrollKey matrix) and `tests/pager-swipe.test.ts` (sequence helper `run(samples)` folding stepSwipe from INITIAL_SWIPE and collecting intents).
