```ts
async function swipe(page: Page, from: { x: number; y: number }, to: { x: number; y: number }, steps = 8, stepMs = 16) {
  const cdp = await page.context().newCDPSession(page);
  await cdp.send("Input.dispatchTouchEvent", { type: "touchStart", touchPoints: [{ x: from.x, y: from.y }] });
  for (let i = 1; i <= steps; i++) {
    const x = from.x + ((to.x - from.x) * i) / steps;
    const y = from.y + ((to.y - from.y) * i) / steps;
    await cdp.send("Input.dispatchTouchEvent", { type: "touchMove", touchPoints: [{ x, y }] });
    await page.waitForTimeout(stepMs);
  }
  await cdp.send("Input.dispatchTouchEvent", { type: "touchEnd", touchPoints: [] });
}
```
(The per-step wait sets the finger speed; it is input timing, not a landing wait.) Tests on the `chromium-touch` project:
- from "/": `swipe({x: 300, y: 400}, {x: 120, y: 405})` -> `waitForLanded`, pathname "/achievements/", focus on `#title-achievements`.
- reverse `swipe({x: 100, y: 400}, {x: 300, y: 400})` -> "/".
- edge exclusion: `swipe({x: 10, y: 400}, {x: 250, y: 400})` -> after `GESTURE_GAP_WAIT_MS`, pathname unchanged and `data-land` unchanged.
- vertical: on "/projects/", `swipe({x: 200, y: 700}, {x: 205, y: 200})` -> pathname unchanged; `window.scrollY > 0` (document scrolled natively, D-07).
- short slow swipe: `swipe({x: 200, y: 400}, {x: 170, y: 400}, 10, 50)` (30px over ~500ms) -> no page.
- end stop: on "/say-hi/" swipe left -> no page.
- phone hold: on "/projects/" scroll to `window.scrollTo(0, 400)`, swipe left -> lands "/experience/" with `scrollY === 0` and `#page-projects` has no inline transform after landing.
