`lib/pager/controller.ts` (`export const REPEAT_GATE_MS = 600;` — UI-SPEC: a fixed constant, not --dur-page, which is 0ms under reduced motion):
```ts
export function createPagerController(deps: PagerDeps, initialIndex: number): PagerController
```
Closure state: `let state = initialState(initialIndex)`, `listeners = new Set<() => void>()`, `reduced = false`, `lastAcceptedAt = -Infinity`, `signals = createSignals()`.
- `intent(i)`: (1) if `i.type !== "goto" && i.repeat && (state.phase !== "idle" || deps.now() - lastAcceptedAt < REPEAT_GATE_MS)` return false. (2) `const prev = state; const next = reduce(prev, i); if (next === prev) return false;` (3) `lastAcceptedAt = deps.now()`; `deps.commit(() => { state = next; notify(); })`. (4) `deps.scroll.beforeSlide(prev.current, next.target, prev.phase === "idle")`. (5) `const id = next.slideId; deps.animator.slideTo(next.target, { retarget: next.retarget, reduced }).then((finished) => { if (finished && state.slideId === id) landNow(); });` (6) `if (prev.phase === "idle") deps.focus.focusTitle(next.target, i.source === "key")`. (7) `signals.emitSlideStart({ from: prev.target, to: next.target, source: i.source })`. return true.
- `landNow()`: `const prev = state; const next = land(prev); if (next === prev) return;` then (a) `if (prev.focusHolder !== prev.target) deps.focus.focusTitle(prev.target, prev.source === "key")` — the landed page is already live, the holder not yet inert (Pitfall 9, WR-06); (b) `deps.commit(() => { state = next; notify(); })`; (c) `deps.animator.settle(next.current)`; (d) `if (prev.source !== "history") deps.history.push(next.current)`; (e) `deps.scroll.afterLand(next.current)`; (f) `signals.emitLanded(next.current)`.
- `getSnapshot` returns `state` (stable reference between changes, required by useSyncExternalStore); `subscribe` adds/removes from the Set.
- No `console.*`, no timers, no DOM access in this file. Functions under 50 lines.
