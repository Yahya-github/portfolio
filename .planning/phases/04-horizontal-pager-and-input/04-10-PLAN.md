   - `currentScroller()`: `scrollerFor(pageElement(controller.getSnapshot().target))`.
   - Wheel: `window.addEventListener("wheel", onWheel, { passive: false })` (Chrome/Safari make window wheel listeners passive by default; never React `onWheel`). In `onWheel(e)`: `const mode = e.deltaMode as 0 | 1 | 2;` read FIRST (Pitfall 5), then `const sample = { mode, dx: e.deltaX, dy: e.deltaY, t: e.timeStamp, ctrl: e.ctrlKey, vh: window.innerHeight, legacy: (e as WheelEvent & { wheelDeltaY?: number }).wheelDeltaY };` `const step = stepWheel(wheelRef, sample, edgeInfo(currentScroller()));` store `wheelRef = step.state`; `if (step.preventDefault) e.preventDefault();` `if (step.intent) controller.intent({ type: step.intent, source: "wheel" });` emitDebug `{ wheel: {t, dx, dy, mode, legacy}, accum: dominant |sum|, gesture: { id, open: phase === "accumulating" || phase === "scrolling" }, edge }` where edge = atEnd ? "bottom" : atStart && overflowing ? "top" : "none". `wheelRef` is a closure `let` inside the effect (not React state).
   - Keys: `window.addEventListener("keydown", onKey)`. Build `KeyEventLike` from the event with `targetKind: targetKindOf(document.activeElement)`; `const k = keyIntent(ev); if (!k) return;` For `first`/`last`: `preventDefault`, `controller.intent({ type: "goto", index: k.action === "first" ? 0 : PAGE_COUNT - 1, source: "key" })`. For next/prev: if `k.scrollFirst`: `const scroller = currentScroller(); const decision = resolveScrollKey(k, edgeInfo(scroller));` "stop" -> `preventDefault` only; "scroll" -> if `document.activeElement` is inside `scroller` (or scroller is `document.scrollingElement` and focus is on body) let the browser scroll natively (no preventDefault); otherwise `preventDefault` and `scroller.scrollBy({ top: dir * (k.scrollBy === "page" ? KEY_PAGE_RATIO * scroller.clientHeight : KEY_LINE_PX), behavior: controller.isReducedMotion() ? "instant" : "auto" })` (Pitfall 8: focus on body would otherwise scroll the non-scrolling document); "page" -> `preventDefault` + `controller.intent({ type: k.action, source: "key", repeat: k.repeat })`. Non-scrollFirst next/prev (arrows left/right) -> `preventDefault` + intent with `repeat`. The 600ms repeat gate is the controller's (plan 04-05).
   - Swipe: `window.addEventListener` for `pointerdown`, `pointermove`, `pointerup`, `pointercancel` (passive). Map each to `PointerSample { kind, x: e.clientX, y: e.clientY, t: e.timeStamp, pointerType: e.pointerType, id: e.pointerId, zoomed: (window.visualViewport?.scale ?? 1) > 1 }`, fold `stepSwipe`, intent with `source: "swipe"`, emitDebug `{ swipe: { dx, v, lock } }`. `touch-action: pan-y pinch-zoom` on html (plan 04-02) keeps vertical scroll native; never call preventDefault on pointer events.
