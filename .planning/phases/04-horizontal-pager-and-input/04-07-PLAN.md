<objective>
Move heading levels from a server prop (`headingLevel`) to a client context (`PageLevel`), and make page titles focus targets.

Purpose: RESEARCH Pattern 1 — server page bodies cannot re-render on client state, so `Heading`/`PageTitle` read the level from a client context that `PageSection` (plan 04-08) will drive from the pager target. UI-SPEC Chrome table: "the target page drops inert and its title becomes h1". A11Y-01 focus target `id="title-{slug}"`, `tabIndex={-1}`.
Output: `PageLevel.tsx`, client `Heading.tsx`, six page bodies without level arithmetic, Track wrapping bodies in the provider, updated tests.
</objective>

```tsx
"use client";
import { createContext, useContext, type ReactNode } from "react";
export type PageLevel = 1 | 2;
const PageLevelContext = createContext<PageLevel>(1);
interface PageLevelProviderProps { readonly level: PageLevel; readonly children: ReactNode }
/** Heading level of a page's title (A11Y-01): 1 for the pager target, 2 elsewhere (RESEARCH Pattern 1). */
export function PageLevelProvider({ level, children }: PageLevelProviderProps) {
  return <PageLevelContext value={level}>{children}</PageLevelContext>;
}
export function usePageLevel(): PageLevel { return useContext(PageLevelContext); }
```
